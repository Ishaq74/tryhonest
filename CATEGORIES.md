This document describes the comprehensive categorization system for places in the Salut Annecy platform.

- Résidence senior

## 💡 Usage dans l'application

### Dans le code

Les catégories sont définies dans `src/types/models.ts`:

```typescript
export type PlaceCategory = 
  | 'accommodation'
  | 'restaurant'
  | 'shop'
  | 'activity'
  | 'culture'
  | 'nature'
  | 'health'
  | 'education'
  | 'transport'
  | 'service'
  | 'institution'
  | 'worship'
  | 'industry';
```

### Dans la base de données

La table `Place` utilise un champ `category` (STRING) et `subcategory` (STRING optionnel) pour une flexibilité maximale.

### Exemple d'utilisation

```typescript
const place = {
  category: 'restaurant',
  subcategory: 'gastronomique',
  attributes: ['terrasse', 'vue-lac', 'vegetarien', 'accessible-pmr']
};
```

## 🎯 Recommandations

1. **Utiliser les sous-catégories** pour des classifications précises
2. **Combiner les filtres** pour des recherches ciblées
3. **Enrichir les attributs** pour améliorer la découvrabilité
4. **Maintenir la cohérence** dans les classifications
